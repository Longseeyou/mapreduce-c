# Project provenance

This project is derived from Nguyen Hoang Long Dinh's C MapReduce and thread-pool
implementation for CMPUT 379 at the University of Alberta.

The original project used course-provided MapReduce/thread-pool interface files,
a word-count example, and test inputs. This standalone repository has a rewritten
public header and examples, a reorganized implementation, and new tests and sample
data. The internal thread-pool types retain their original interface lineage.
Course handouts, grading records, original datasets, and the source repository's
Git history are not included.

The original implementation README recorded these development references:

- https://deepwiki.com/quantumish/mapreduce/1-overview
- https://github.com/Pithikos/C-Thread-Pool
- https://www.youtube.com/watch?v=cvhKoniK5Uo
- POSIX system headers for pthreads, stat, and related types.

These references record the existing project's provenance; they do not imply
endorsement or that this repository contains those projects' code.
